# Notes — Embedded Named Notes / Notes as First-Class Entity (Option D)

Parked for later. Revisit when needed.

Notes become a first-class entity (not a string field on a task). Every task auto-creates a linked root note. Selecting text in a note and right-clicking lets you "Name this" — the selection collapses to an inline expandable chip and becomes its own child note, infinitely nestable. The Notes Viewer sidebar becomes note-centric, showing the full tree.

See `autobot-notes-findability.md` for the original ASCII mocks, data model spec, and full discussion.
